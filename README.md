This is the monorepo for the code samples on docs.temporal.io.

The Docs team is responsible for writing new code and making sure existing code stays up to date with help from Engineering for technical reviews. Then we can use snipsync to get the code we want to show in the docs.

Each folder has a sandbox environment for each SDK language and they can be worked on independently.

PRs should be made for all changes, but they don't have to be strictly reviewed as long as:

- All of the linting issues are fixed
- The code still runs like it did before
